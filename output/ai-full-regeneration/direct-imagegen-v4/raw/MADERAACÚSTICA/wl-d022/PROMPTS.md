# MADERAACÚSTICA/wl-d022 — direct ImageGen prompts

Tool mode: built-in ImageGen. Each attempt was an independent call whose only reference was `public/images/PUERTAS/MADERAACÚSTICA/wl-d022/original.webp`.

Every prompt required the same full front-facing product: complete rectangular frame and threshold, narrow left stile, large upper panel, wide contrasting horizontal insert at handle height with straight seams, large lower panel, one lever, and one round key escutcheon. It also prohibited logos, badges, text, pseudo-text, extra hardware, scenes, halos, patches, redesign, crop, and missing components.

The nine independent finish instructions were: negro, wengue, gris oscuro, antracita, nogal, roble, gris claro, natural, and blanco. Each changed only the material/color and kept the horizontal insert subtly lighter than the surrounding leaf.

Wengue used a second direct ImageGen attempt requesting tighter edge-to-edge framing. The first raw result remains under `_rejected/`; it was not cropped, resized, recolored, masked, or composited.

All active PNG files are byte-for-byte copies of their built-in ImageGen outputs. No conversion or public write has occurred.
